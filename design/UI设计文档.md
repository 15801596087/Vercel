## 一、页面与状态总览

| 页面 | 作用 |
|------|------|
| 主计时页面 | 默认首页，完成专注/休息倒计时的核心操作 |
| 设置页面 | 调整专注/休息时长、提示音，管理数据 |

**计时状态机**：

```
未开始 ──▶ 专注中 ──(到点)──▶ 休息中 ──(到点)──▶ 专注中 ──…循环
              │ 随时可 暂停 / 重置 / 跳过
```

- **未开始**：圆盘显示预设的专注时长（如 25:00），按钮为「▶ 开始」。
- **专注中 / 休息中**：圆盘倒计时，按钮变为「⏸ 暂停」。
- **到点**：播放提示音，自动进入下一阶段，圆盘颜色随之切换（专注=主色，休息=辅色）。

## 二、主计时页面

### 2.1 布局描述（自上而下）

| 区域 | 内容 | 视觉规范 |
|------|------|----------|
| 顶部 | 产品名「番茄专注 🍅」 | 左对齐，H1（24px / 600），Text-Primary |
| 状态标签 | 「专注中」/「休息中」/「准备开始」 | Caption（14px / 500），胶囊底 Primary-100 / Secondary-100 |
| 倒计时圆盘 | 剩余时间 `mm:ss` + 阶段小字 | 圆盘 240px，圆环 8px；数字 72px / 700 等宽；专注主色、休息辅色 |
| 控制按钮 | 「▶ 开始 / ⏸ 暂停」+「↺ 重置」 | 主按钮 + 文字按钮，水平居中 |
| 完成统计 | 「今日已完成 🍅 × 3」 | Caption（14px），Text-Secondary，Success 色强调数字 |
| 底部入口 | 「⚙ 设置」 | 图标按钮 / 文字按钮，右下角 |

### 2.2 交互说明

1. **开始 / 暂停**：同一主按钮切换文案与图标（▶ / ⏸）。未开始时点击进入「专注中」并开始倒计时；再次点击暂停，圆盘数字冻结。
2. **重置**：回到当前阶段的初始时长并停止计时（停在「未开始」状态）。
3. **阶段切换**：专注到点 → 提示音 → 自动进入休息并开始倒计时，圆盘颜色由主色转辅色；休息到点同理回到专注。
4. **提示音**：到点自动播放（默认开，可在设置页关闭或更换）。
5. **设置入口**：点击跳转到设置页面；从设置页「返回」回到本页时计时状态保留。

## 三、设置页面

### 3.1 布局描述（自上而下）

| 区域 | 内容 | 视觉规范 |
|------|------|----------|
| 顶部 | 「← 返回」+ 标题「设置」 | 返回用文字按钮（Primary-500），标题 H1 |
| 时长分组 | 专注时长、休息时长（数字输入 + 步进） | 卡片内，每行「标签 + 输入框」，H2 分组标题 |
| 提示音分组 | 提示音开关、提示音选择 | 开关组件 + 下拉选择 |
| 数据分组 | 数据导出、数据导入 | 次按钮，带说明文字 |
| 底部 | 关于 / 版本号 v0.1 | Micro（12px），Text-Disabled |

### 3.2 交互说明

1. **时长调整**：通过数字输入或「+ / −」步进修改专注/休息时长，单位分钟；改动**即时保存**到浏览器本地缓存（`localStorage`），无需额外「保存」按钮。
2. **提示音开关**：开关开启时，到点播放提示音；关闭则静音。
3. **提示音选择**：下拉选择音效（默认 1 种，后续迭代增加）。
4. **数据导出**：将本地缓存（时长设置、提示音设置、完成统计）导出为 JSON 文件下载。
5. **数据导入**：选择 JSON 文件，校验通过后覆盖本地数据并刷新界面。
6. **返回**：回到主计时页面，计时状态保持不变。

## 四、关键交互状态对照

| 场景 | 圆盘颜色 | 按钮文案 | 说明 |
|------|----------|----------|------|
| 未开始 | 主色（专注） | ▶ 开始 | 显示预设专注时长 |
| 专注中 | 主色 | ⏸ 暂停 | 数字递减 |
| 暂停 | 主色 | ▶ 继续 | 数字冻结 |

| 休息到点 | 转主色 | ⏸ 暂停 | 播放提示音，自动进入专注，完成数 +1 |

## 五、响应式与无障碍

- **响应式**：单列窄布局（内容最大宽 480px 居中）；移动端左右边距 16px，桌面端 24px。
- **无障碍**：所有按钮有明确文字/图标说明；倒计时数字等宽不抖动；颜色不作为唯一信息载体（状态另有文字标签）。
