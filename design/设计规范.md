# 番茄专注 · 设计规范

> 状态：草案 v0.1（默认占位值，待对照参考图确认替换）　|　日期：2026-10-08
> 说明：本规范中所有配色、字号、间距、圆角均为**暂定的默认值**，尚未对照参考截图校准；确认参考风格后请逐项替换。

---

## 一、设计原则

- **专注**：界面极简，弱化装饰，让倒计时成为唯一视觉焦点。
- **清爽**：大量留白 + 低饱和中性色，长时间使用不疲劳。
- **一致**：配色、圆角、间距、组件全部收敛到一套 Token，便于扩展。

## 二、配色方案

|------|-------|------|------|

## 三、字体规范

### 3.1 字体族

| 用途 | 字体栈 |
|------|--------|
| 中文 / 正文 | `-apple-system, BlinkMacSystemFont, "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", "Helvetica Neue", Arial, sans-serif` |
| 倒计时数字（等宽） | `"SF Mono", SFMono-Regular, Menlo, Consolas, "Roboto Mono", monospace` |

> 倒计时数字采用等宽字体，避免秒数跳动时数字宽度变化导致抖动。

### 3.2 字号层级

| 层级 | 字号 | 行高 | 字重 | 用途 |
|------|------|------|------|------|
| Display | 72px | 1.0 | 700 | 倒计时圆盘主数字 |
| H1 | 24px | 32px | 600 | 页面标题 |
| H2 | 18px | 26px | 600 | 卡片标题、分组标题 |
| Body | 16px | 24px | 400 | 默认正文、说明 |
| Caption | 14px | 20px | 400 | 次要说明、标签 |
| Micro | 12px | 16px | 400 | 脚注、版本号 |

### 3.3 字重

| 字重 | 数值 | 用途 |
|------|------|------|
| Regular | 400 | 正文、辅助说明 |
| Medium | 500 | 标签、状态文字 |
| Semibold | 600 | 标题、按钮文字 |
| Bold | 700 | 倒计时数字 |

## 四、间距规则

以 **4px 为基础栅格**（4 的倍数），统一 Token。

| Token | 值 | 用途 |
|-------|-----|------|
| space-1 | 4px | 图标与文字间距、紧密元素 |
| space-2 | 8px | 分组内相关元素间距 |
| space-3 | 12px | 卡片内紧凑间距、输入框内边距 |
| space-4 | 16px | 常规元素间距 |
| space-5 | 24px | 卡片内边距、区块间距 |
| space-6 | 32px | 页面级区块间距 |
| space-7 | 48px | 大区块 / 首屏留白 |

- **页面左右边距**：移动端 16px，桌面端 24px。
- **内容最大宽度**：桌面端容器居中，最大 480px（计时器属单列窄布局）。

## 六、组件样式

### 6.1 按钮 Button

| 类型 | 样式 |
|------|------|
| 主按钮 | 背景 Primary-500、文字白色；圆角 radius-m（12px）；高度 48px；左右内边距 24px；字号 16px / 字重 600。hover 用 Primary-600；active 再加深。 |
| 次按钮 | 背景 Surface（白）、1px 边框 Border；文字 Text-Primary；尺寸同主按钮。hover 边框转 Primary-500、背景 Primary-100。 |
| 文字按钮 | 无背景无边框，文字 Primary-500；用于「返回」「重置」等次级入口。 |
| 图标按钮 | 44px 圆形；hover 背景 `#F0EEE9`。 |

**状态**：
- `disabled`：背景 `#E0DFDC`、文字 `#B0AFAC`，不可点击。
- `active`：按下时背景加深（主按钮 Primary-600，次按钮 Primary-100）。

### 6.2 卡片 Card

- 背景 Surface（白）、圆角 radius-l（16px）、内边距 24px（space-5）。
- 阴影：`0 2px 8px rgba(0, 0, 0, 0.06)`。

### 6.3 输入框 Input

- 背景 Surface（白）、1px 边框 Border、圆角 radius-s（8px）、高度 44px、左右内边距 12px。
- `focus`：边框 Primary-500，外发光 `0 0 0 3px rgba(255, 107, 53, 0.15)`。
- `disabled`：背景 `#F7F6F3`、文字 Text-Disabled。
- 数字输入右侧可带「+ / −」步进按钮。

### 6.4 开关 Switch

- 尺寸 44px × 24px，圆角 radius-full。
- 关闭态：背景 `#D9D7D2`；开启态：背景 Primary-500。
- 滑块：20px 白色圆形，开启时右移。

### 6.5 倒计时圆盘 Timer Ring

- 直径 240px 圆形，圆环宽 8px。
- 专注态圆环 Primary-500，休息态圆环 Secondary-500。
- 圆环随剩余时间递减（可选：环形进度条）。
- 中央为等宽大数字（Display 72px / 700），下方小字标注当前阶段（专注 / 休息）。
