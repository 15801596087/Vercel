# 番茄专注（Web 番茄钟）PRD

> 状态：草案 v0.1　|　作者：胡淑芳　|　日期：2026-10-08
> 内容来源：`fanqie/RDs/产品需求.md`

---

## 一、产品概述

一个**打开浏览器即用、无需下载安装**的番茄钟专注工具，帮助需要专注工作或学习的人，通过"25 分钟专注 + 5 分钟休息"的节奏管理时间、提升专注效率。

---

## 二、目标用户

| 用户 | 特征与诉求 |
|------|-----------|
| 学生 / 备考人群 | 需要整块专注时间学习，用番茄节奏对抗拖延 |
| 上班族 / 自由职业者 | 需要集中精力处理工作，减少分心 |
| 轻量工具偏好者 | 不想安装软件、注册账号，打开网页就能开始计时 |

**共同特征**：单机使用、轻度留存，希望"零门槛开始"，不需要复杂统计或社交功能。

---

## 三、核心功能清单

### P0（MVP 必须，第一版上线）

| 功能 | 说明 |
|------|------|
| 专注倒计时 | 默认 25 分钟专注倒计时，实时显示剩余时间 |
| 休息倒计时 | 专注结束后自动进入 5 分钟休息倒计时 |
| 开始 / 暂停 / 重置 | 计时器的三个核心控制操作 |
| 完成提示音 | 专注或休息结束时播放提示音提醒用户 |

### P1（重要，第二阶段）

| 功能 | 说明 |
|------|------|
| 自定义时长 | 用户可自行设置专注时长、休息时长 |
| 设置页面 | 独立的设置页，用于调整时长等参数 |
| 本地缓存持久化 | 设置项保存到浏览器本地缓存，下次打开自动生效 |

### P2（增强，后续迭代）

| 功能 | 说明 |
|------|------|
| 数据导出 / 导入 | 将本地数据（设置、完成记录）导出为文件，可导入恢复 |
| 提示音选择 / 开关 | 多套提示音可选，支持静音 |
| 完成统计 | 展示今日/累计完成的番茄数 |

---

## 四、页面结构

| 页面 | 功能 |
|------|------|
| 主计时页面 | 倒计时显示、专注/休息状态展示、开始/暂停/重置控制、今日完成数、设置入口 |
| 设置页面 | 调整专注时长、休息时长、提示音开关/选择、数据导出与导入 |

---

## 五、页面框架图

### 5.1 主计时页面

```
┌──────────────────────────────────────┐
│  番茄专注 🍅                         │  ← 顶部标题栏
├──────────────────────────────────────┤
│                                      │
│        【专注中】 / 【休息中】         │  ← 当前状态标签
│                                      │
│            ╭────────────╮           │
│            │    24:59    │           │  ← 倒计时大圆盘
│            │  （剩余时间） │           │
│            ╰────────────╯           │
│                                      │
│         [ ▶ 开始 ]   [ ↺ 重置 ]      │  ← 控制按钮（开始/暂停切换）
│                                      │
│   今日已完成：🍅 × 3                  │  ← 完成统计
│                                      │
│                   ⚙ 设置 →           │  ← 进入设置页
└──────────────────────────────────────┘
```

**区域说明**：
- **顶部标题栏**：产品名称，固定不变。
- **状态标签**：区分当前处于「专注」还是「休息」阶段。
- **倒计时大圆盘**：核心视觉区，大字显示剩余时间（mm:ss）。
- **控制按钮**：开始与暂停为同一按钮切换；重置可重新开始当前阶段。
- **完成统计**：展示今日完成的番茄数量，给用户正向反馈。
- **设置入口**：点击跳转到设置页面。

### 5.2 设置页面

```
┌──────────────────────────────────────┐
│  ← 返回      ⚙ 设置                  │  ← 顶部（返回主计时页）
├──────────────────────────────────────┤
│                                      │
│  专注时长          [ 25 分钟 ]        │  ← 数字输入/步进
│  休息时长          [  5 分钟 ]        │  ← 数字输入/步进
│                                      │
│  提示音            [ 开 ]  [ 关 ]     │  ← 开关
│  提示音选择        [ 音效 A ▾ ]       │  ← 下拉选择
│                                      │
│  ─────────────────────────────────   │
│  数据导出          [ 导出 ]           │  ← 下载数据文件
│  数据导入          [ 导入 ]           │  ← 上传数据文件
│                                      │
│  ─────────────────────────────────   │
│  关于 / 版本       v0.1              │
└──────────────────────────────────────┘
```

**区域说明**：
- **顶部**：「← 返回」回到主计时页面。
- **时长设置**：调整专注时长与休息时长，修改后即时保存到本地缓存。
- **提示音设置**：控制提示音开关与具体音效选择。
- **数据导出 / 导入**：将本地缓存数据导出为文件，或从文件导入恢复。
- **关于**：展示版本号等信息。

## 六、数据与存储说明

| 项 | 方案 |
|----|------|
| 存储位置 | 浏览器本地缓存（`localStorage`） |
| 存储内容 | 专注/休息时长设置、提示音设置、完成统计 |
| 持久化时机 | 设置变更时即时写入 |
| 导出/导入 | 导出为 JSON 文件；导入时校验并覆盖本地数据 |
